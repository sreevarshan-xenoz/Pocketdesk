# The T cycle (2026-10-24), after S and 0.6.0

The S cycle ran the owed checks that could run here and fixed what they found. This cycle goes back to building, from what people asked of tools like Pocketdesk in 2025–2026 (KDE Connect's tracker and forum, GSConnect, LocalSend, Phone Link, Intel Unison's users after it closed, Syncthing's users after its Android app was retired), each gap checked against the code. It removes this plan when it ends.

Each item is a branch and a PR, with its design and review in the PR and its entry in `docs/status-history.md`; gates, a fresh review, and a check on the OPPO or the Azure VM where one can run.

| # | Item | Why | Where |
|---|---|---|---|
| T1 | Start beside KDE Connect | `kdeconnectd` (on every Plasma install) or GSConnect holding TCP 1716 stops Pocketdesk's server from starting (README says so). Take the next free port, announce it, and leave the KDE bridge off while another program holds 1716. | computer |
| T2 | The clipboard on X11 | Text and images cross only through `wl-copy`/`wl-paste`; Mint and others still default to X11. `xclip` (as copied files already use) with a watcher. | computer (Linux) |
| T3 | Photos to the computer by themselves | Syncthing's Android app is gone; only screenshots go by themselves now. New camera photos and videos, opt-in, on Wi-Fi, resumable, as T10h's screenshots. | phone |
| T4 | The whole photo gallery | C7 shows the newest 24. Pages, videos, saving several, HEIC copied as PNG. | both |
| T5 | Folders from one computer to the other | 2h sends a folder from B to A only; A to B is refused. | computer |
| T6 | Files to a KDE Connect device | The bridge takes a KDE device's files but cannot send it any: this computer never dials out to one. | computer |
| T7 | A game controller on Linux | The phone's gamepad reaches the computer as keys; a uinput pad that games see as a controller. | computer (Linux) |
| T8 | Lock when the phone leaves on Sway and Hyprland | The idle time from `ext-idle-notify-v1` where GNOME's and KDE's are missing. | computer (Linux) |
| T9 | A second screen and one window on GNOME and KDE | The portal's virtual and window sources, where the second screen is Sway-only and window streaming Hyprland-only. | computer (Linux) |

## Not in it: waiting for the owner's go

- The phone as the computer's webcam (it registers a camera device on the computer).
- One-time codes on the computer, opt-in (Pocketdesk replaces them on purpose today).
- Picture messages and group texts (the owner's SIM; Play's SMS policy).
- Sending to a device without the app by a browser link (a new LAN listener and a firewall rule).
- Receiving from Quick Share (a reverse-engineered protocol and a Bluetooth advert).
- Unlocking the computer with the phone's fingerprint (a security component, never tested on this box).
