# The AX cycle (2026-10-26), after AW

AQ3, AR1 and AV3 were each a saved computer's state reaching where it should not. This cycle follows that kind to the phone's own Home: an audit of what still points at a computer after its card is removed, renamed or moved (O3) found these, each to fix as its own PR (Phase R). It removes this plan when it ends.

| # | Item | Where | Checkable here |
|---|---|---|---|
| AX1 | Removing a card leaves the phone's live control link to that computer up: it can still ring the phone and press its media keys, and the computer that becomes the phone's own is never linked while it lasts (every background dial waits for no link). Remove closes the link when it goes to that computer. Checked on the OPPO with a second card for the throwaway (localhost), paired, its link up, then removed | `android/app`, `android/bridge` | Yes |
| AX2 | A move (O3, a saved computer seen at a new address) leaves other cards' "wake through this computer" at the old address, so their Wake fails "no longer saved" while it shows. A move carries them to the new address | `android/app` | Yes (unit tests) |
| AX3 | A removed computer's pick under "also send notifications to" stays, unlisted, counting toward the four. Remove drops it | `android/app` | Yes (unit tests) |
| AX4… | A fix for each FAIL found, as its own PR | | Yes |

## Not in it

- Pinned shortcuts and the deck widget keyed by address across a move or a new computer at an old address, and the bridge's name cache by address: lower, noted in AX's end.
- "Pocketdesk control", the owner-gated list, and the 0.7.0 tag.
