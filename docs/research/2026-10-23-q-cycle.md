# The Q cycle (2026-10-23), after P

The P cycle is built (P1 to P11). A look at 2026's requests found little new that Pocketdesk lacks:
- **KDE's Discuss and bug tracker:** SMS from the desktop, microphone sharing, clipboard sync, gamepad emulation, an intent listener.
- **Phone Link:** call transfer, which needs the phone's call audio; Android does not let an app capture it.
- **Android 17's Continue On:** it moves apps between Android devices only.

So this cycle makes what the O and P cycles built checkable and finished, rather than adding more. It removes this plan when it ends.

## Q1. The O and P cycles' device checks, run by script

**What:** `scripts/device_checks.py` gains a check for each O or P item a script can drive against a throwaway server:
- **The apps:** P2's list and open.
- **Holds:** P3's presenting and quiet hours; P4's words.
- **Alarms:** P5's alarm, with the server paused.
- **Files:** P6's several targets, by the CLI; P7's copied files, through the seams.
- **Contacts:** P10's contacts, counts only, the file deleted.
- **Ring:** P11's vibration and torch, read from `dumpsys`.

Each check prints PASS, FAIL, SKIP or TIMEOUT, as N1's do. The pure parts get unit tests in CI.

**Checked:** run on the OPPO; every check passes, or SKIPs with its reason.

## Q2. A design pass on what O and P added to the desktop app

**What:** the pages that grew:
- Settings' Notifications section: quiet hours, holding by words, alarms;
- Settings' Phones section: links by site;
- Files: "Also to…";
- Messages: contacts;
- Devices: profiles;
- the Overview: the phone's buttons.

An audit against the U1/U5 rules (one notice, rows that wrap, words, empty states, screen-reader names), fixed in groups.

**Checked:** the harness and the snapshots, redrawn.

## Q3. A design pass on what O and P added to the phone

**What:** the phone's Settings rows from O and P:
- the contacts, apps and alarm switches;
- the kinds of notifications;
- copies kept by program or look;
- the player choice;
- the ring's switches.

Checked for order, words, Spanish and Tamil, font scale 2.0 and TalkBack labels.

**Checked:** on the OPPO, by `uiautomator`.

## Q4. Linux catch-up for P

**What:**
- **P3:** presenting from GNOME's and KDE's own Do Not Disturb (`org.freedesktop.Notifications` inhibition, or the portal's).
- **P5:** an alarm's sound on Linux (a sound hint).
- **P7:** files copied on X11 (`xclip -t text/uri-list`).

Each falls back as now where the desktop says nothing.

**Checked:** on the Azure VM (Sway), within the budget rule; GNOME and KDE owed.

## Q5. A release candidate, 0.6.0

**What:** the release checklist's dry run on the merged O and P cycles: versions, the APK signed with the release key, the archives, the sums. The tag waits for the owner's go.

**Checked:** the dry run's files, as 0.5.0's were.

## Not taken

- **Call audio on the computer:** Android gives no app the call's audio.
- **Continue On:** it is between Android devices only.
- **A virtual webcam (F6 part 2):** it still waits for the owner's OK.
