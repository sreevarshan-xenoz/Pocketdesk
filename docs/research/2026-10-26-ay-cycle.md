# The AY cycle (2026-10-26), after AX

AX audited what the phone keeps of a computer it lets go; this cycle audits the computer's side: what still lets a phone act, receive, or show, once it is unpaired (the CLI, the desktop app's Unpair, a guest grant ending). The audit's findings, each fixed as its own PR (Phase R). It removes this plan when it ends.

| # | Item | Where | Checkable here |
|---|---|---|---|
| AY1 | Security: the v2 control stream checked a phone's key only at its handshake, where an unpaired id has none to check, and then asked each packet only whether the id is paired. A session opened claiming an unpaired phone's id, with another key, would act with that phone's permissions once the real phone paired again. Each packet is judged as the TCP gate judges it, pairing and key re-read (one `may_act` for the TCP gate, the push filter and v2) | `server` | Yes (unit tests; the runner's session and pairing checks against the fixed server) |
| AY2 | A task the owner allowed after its phone was unpaired still runs, and its output reaches that phone's connection, which an unpair blocks but does not close. The task checks the phone's standing before it runs and before its output goes | `server` | Yes |
| AY3 | The desktop app's Unpair ends that phone's sessions by its id as a kick target, where `all` or a prefix of another phone's id kicks others too. The sessions are ended by their session ids (which the watcher already does) | `desktop` | Yes (unit tests) |
| AY4 | A guest grant that ends fires no `phone_unpaired` event or hook until something else writes the trust store: the watcher reads it only when the file changes | `server` | Yes (unit tests) |
| AY5 | An unpaired phone's notifications, live cards and texts stay on the Notifications and Messages pages until the server restarts. They go when it is unpaired | `server`, `core` | Yes |
| AY6… | A fix for each FAIL found, as its own PR | | Yes |

## Not in it

- `relay --allow-paired` checking only as a connection opens: bandwidth only, the computer refuses the phone itself.
- "Pocketdesk control", the owner-gated list, and the 0.7.0 tag.
