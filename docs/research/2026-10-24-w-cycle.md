# The W cycle (2026-10-24), after V

The V cycle found that a session runs from the OPPO to a throwaway server over the internet road, with the phone's input off, and its probes turned up two bugs in the session's start (V7, V8). Those probes were scratch scripts. Of the owed checks that run here, most left are about sessions and long transfers. So this cycle makes the session probes part of the device-check runner, then uses them and the internet road for what is left (Phase R: prove what exists before adding more). It removes this plan when it ends.

Each item is a branch and a PR (fixes found get their own), with its design and review in the PR and its entry in `docs/status-history.md`.

| # | Item | Where | Checkable here |
|---|---|---|---|
| W1 | `scripts/device_checks.py` starts a session over the internet road (input off, checked first) and reads the HUD from UI dumps: checks for §2d's caption and basis reset, a session's time to connect from away (V8), and an hour's memory and frame rate (§16, §46) | The OPPO, a throwaway server | Yes |
| W2 | A session's loss response from the server's log: no bitrate change on a quiet desktop (§11), and the HUD presets' rebuild (§11b) as far as the log shows it | The OPPO, a throwaway server | Yes |
| W3 | The long transfers in "Here" over the internet road, where files ride the link: a file over 1 GB both ways, a download cut and continued (§31, §50), a folder of thousands (§52) | The OPPO, a throwaway server | Yes |
| W4 | Polish of the phone's session screen, from UI dumps and the HUD's text: the caption in portrait (§2d), the error card's words for a stop, a drop and a refusal, TalkBack labels on its controls | The OPPO | Yes |

## Not in it

- T9, a second screen and one window on GNOME and KDE: it needs one of those desktops to build against (the T cycle's end entry has its mapping).
- V8's home-again case: back home with the link still by the internet road, the session's short home try answering. It needs the phone away and then home.
- The owner-gated list carries over: the phone as a webcam, one-time codes, picture messages and group texts, a browser link for devices without the app, receiving from Quick Share, and unlocking with the phone's fingerprint.
