# The U cycle (2026-10-24), after T

The T cycle built eight features. Four of them run only on Linux (T2 the X11 clipboard, T7 the game controller, T8 the away lock on Sway and Hyprland, T1's bind on a box where KDE Connect holds 1716), and two need a second computer or a KDE device (T5, T6). None of those ran on a real desktop. Of the 902 owed checks, 171 need a Linux desktop and 29 a second computer. So this cycle proves what was built before adding more (Phase R), on the Azure VM, and gives both apps a polish pass. It removes this plan when it ends.

Each item is a branch and a PR (fixes found get their own), with its design and review in the PR and its entry in `docs/status-history.md`.

| # | Item | Where | Checkable here |
|---|---|---|---|
| U1 | The T cycle on Linux: T2's clipboard under X11 (Xvfb, `xclip`), T7's controller (`evtest` on uinput), T8's away lock (headless Sway, the lock seam), T1 beside a listener on 1716; fixes found | The Azure VM, the OPPO by the internet road | Yes |
| U2 | The Linux owed checks the VM can run (headless Sway, X11 under Xvfb), S-cycle style: run, tick or rewrite to what they showed | The Azure VM | Yes |
| U3 | The VM as a second computer: T5's folders both ways, the clipboard and files between computers (2g, 2h) | This box and the VM | Yes |
| U4 | Polish of the desktop app's pages the T cycle touched (Phone page photos, Files page targets, Settings rows), from the headless snapshots: layout, wording, empty states, dark mode | `desktop/` snapshots | Yes |
| U5 | Polish of the phone's Settings rows the T cycle added (camera photos, recent photos' videos), from the OPPO's screens: spacing, wording in three languages, TalkBack labels | The OPPO | Yes |

## Not in it

- T9, a second screen and one window on GNOME and KDE: needs one of those desktops to build against (the T cycle's end entry has its mapping).
- The owner-gated list carries over: the phone as a webcam, one-time codes, picture messages and group texts, a browser link for devices without the app, receiving from Quick Share, unlocking with the phone's fingerprint.
